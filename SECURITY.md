# Segurança

## Reportar uma vulnerabilidade

Se você encontrar uma vulnerabilidade de segurança neste repositório (por exemplo, no site estático em `docs/`, em scripts ou em como o conteúdo é servido), pedimos que **não** abra uma issue pública.

### Como reportar

Envie um relato de forma privada:

- **E-mail:** [tiagocosmai@gmail.com](mailto:tiagocosmai@gmail.com)  
  Use um assunto claro, por exemplo: `[study-materials] Relato de segurança`.

Inclua, se possível:

- Descrição da vulnerabilidade
- Passos para reproduzir
- Impacto esperado
- Sugestão de correção (opcional)

### O que você pode esperar

- **Confirmação:** em até alguns dias úteis, confirmaremos o recebimento do relato.
- **Atualização:** informaremos sobre a análise e eventuais correções, na medida do possível, mantendo sua identidade em sigilo se você assim desejar.
- **Crédito:** se quiser ser citado pela descoberta, indique no relato; caso contrário, o relato será tratado de forma anônima.

### Escopo

Este repositório contém principalmente **documentação e conteúdo estático** (Markdown, HTML/CSS/JS para GitHub Pages). Vulnerabilidades em dependências de terceiros (CDN, bibliotecas usadas no site) também são relevantes — descreva onde e como o problema se manifesta.

Obrigado por ajudar a manter o projeto mais seguro.
