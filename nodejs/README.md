# Node.js – runtime, arquitetura e ecossistema

Estudo dirigido sobre **Node.js**: história e posicionamento, funcionamento do **runtime** (V8, **libuv**, *event loop*), princípios de **arquitetura limpa**, **hexagonal** e **SOLID** no contexto JavaScript/TypeScript, principais **frameworks** e **ORMs** (mapeadores objeto-relacional), **instalação** prática e **comparação** com ecossistemas como **Java** e **Python**.

Os diagramas estão em **Mermaid** nos capítulos (renderizados em visualizadores Markdown e no [site GitHub Pages](https://tiagocosmai.github.io/study-materials/) quando o tema suportar).
