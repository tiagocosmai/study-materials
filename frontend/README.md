# Frontend

Sessão sobre **interfaces web e móveis**: fundamentos (**HTML**, **CSS**, **JavaScript**), **Tailwind CSS**, ecossistemas **React** (incluindo Context API, Redux, integração com Tailwind e **WebSockets**), **React Native**, **Vue**, **Angular**, **Svelte**, **Next.js**, **Flutter** e arquiteturas **micro frontend** (Module Federation, single-spa). Cada capítulo combina conceitos, diagramas Mermaid quando útil e **exemplos de código**.
